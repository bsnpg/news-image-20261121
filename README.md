**One page that sums up Saturday 21 November 2026.** A newspaper front page drawn
in code: 36 stories across 7 regions, led by COP31 slipping into overtime with
no deal, three Houthi missiles shot down over Riyadh, and a magnitude 6.7 quake
in central Peru — with a world map, a briefs list, and a date check that leaves
Friday's news out. Every story is verified against a high-credibility source
and attributed beside it, and the image is drawn with Python's Pillow library
(see `make_image.py`).

## Run it

```sh
python3 main.py
```

The program copies `entry.png` to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png` outside the grader). To redraw the image from
scratch:

```sh
python3 make_image.py
```
